# 数据库连接问题排查指南

## 错误信息
```
Error: Connection terminated unexpectedly
Using 'pg' driver for database querying
```

## 快速诊断

运行诊断脚本：
```bash
cd admin
pnpm db:check
```

## 常见问题及解决方案

### 1. PostgreSQL 服务未运行

**Windows:**
```bash
# 检查服务状态
sc query postgresql-x64-XX

# 启动服务
net start postgresql-x64-XX
# 或通过服务管理器启动
```

**macOS (Homebrew):**
```bash
# 检查服务状态
brew services list | grep postgresql

# 启动服务
brew services start postgresql@XX
```

**Linux:**
```bash
# 检查服务状态
sudo systemctl status postgresql

# 启动服务
sudo systemctl start postgresql
```

### 2. 数据库配置错误

检查 `.env.local` 文件中的配置：

```env
# PostgreSQL 配置示例
DATABASE_DIALECT=postgres
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_USERNAME=postgres
DATABASE_PASSWORD=your_password
DATABASE_NAME=memorybook

# 或使用连接字符串
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/memorybook
```

### 3. 数据库不存在

创建数据库：
```sql
-- 连接到 PostgreSQL
psql -U postgres

-- 创建数据库
CREATE DATABASE memorybook;

-- 退出
\q
```

### 4. 连接超时

如果数据库在远程服务器，检查：
- 防火墙设置
- 网络连接
- PostgreSQL 的 `pg_hba.conf` 配置

### 5. 权限问题

确保用户有足够权限：
```sql
-- 授予权限
GRANT ALL PRIVILEGES ON DATABASE memorybook TO your_username;
```

## 临时解决方案

如果暂时无法连接数据库，可以：

1. **使用 SQLite 进行本地开发**（需要修改配置）
2. **使用 Docker 运行 PostgreSQL**：
   ```bash
   docker run -d \
     --name postgres-memorybook \
     -e POSTGRES_PASSWORD=postgres \
     -e POSTGRES_DB=memorybook \
     -p 5432:5432 \
     postgres:15
   ```

3. **使用云数据库**（如 Supabase、Neon）

## 验证连接

运行诊断脚本后，如果看到：
```
✅ PostgreSQL 连接成功！
   服务器时间: 2026-01-28 12:00:00
```

说明连接正常，可以继续执行 `pnpm db:push`。

## 下一步

连接成功后，执行：
```bash
pnpm db:push
```

这将同步所有新增的表结构到数据库。
