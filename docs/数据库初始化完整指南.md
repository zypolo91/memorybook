## 🚀 方法一：使用 Supabase SQL Editor (推荐)

### 步骤 1: 创建表结构

1. 登录 [Supabase Dashboard](https://supabase.com/dashboard)
2. 选择你的项目
3. 点击左侧 **SQL Editor**
4. 点击 **New Query**
5. 复制并粘贴以下文件内容：

```
📁 admin/drizzle/pg/restore_all_tables.sql
```

6. 点击 **Run** 或按 `Ctrl+Enter`
7. 等待执行完成，应该看到类似输出：

```
NOTICE:  ✅ 所有表结构已恢复！
NOTICE:     原有表: memories, memory_media, tags, memory_tags, albums, album_memories
NOTICE:     原有表: family_circles, family_members, patients
...
```

### 步骤 2: 插入种子数据

1. 在 SQL Editor 中新建另一个查询
2. 复制并粘贴以下文件内容：

```
📁 admin/drizzle/pg/seed_data.sql
```

3. 点击 **Run** 执行
4. 应该看到输出：

```
NOTICE:  ✅ 种子数据插入完成！
NOTICE:     - 12 个标签 (tags)
NOTICE:     - 21 条健康指南 (health_guides)
NOTICE:     - 7 个病例分类 (medical_categories)
NOTICE:     - 8 个病例标签 (medical_tags)
```

### 步骤 3: 验证表结构

在 SQL Editor 执行以下查询：

```sql
-- 查看所有表
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public' 
  AND table_type = 'BASE TABLE'
ORDER BY table_name;
```

应该看到以下表（共 20+ 个）：

## 🖥️ 方法二：使用 psql 命令行

### 前提条件

- 已安装 PostgreSQL 客户端 (psql)
- 已获取 Supabase 数据库连接信息

### 步骤 1: 获取连接信息

在 Supabase Dashboard:
1. 点击 **Project Settings** (左下角齿轮图标)
2. 点击 **Database**
3. 找到 **Connection string** 部分
4. 复制 **URI** (类似下面格式):

```
postgresql://postgres:[YOUR-PASSWORD]@db.xxxxx.supabase.co:5432/postgres
```

### 步骤 2: 执行 SQL 脚本

#### Windows PowerShell:

```powershell
# 进入 admin 目录
cd F:\memorybook\admin

# 执行表结构恢复
$env:PGPASSWORD="your-password-here"
psql -h db.xxxxx.supabase.co `
     -U postgres `
     -d postgres `
     -p 5432 `
     -f drizzle\pg\restore_all_tables.sql

# 执行种子数据插入
psql -h db.xxxxx.supabase.co `
     -U postgres `
     -d postgres `
     -p 5432 `
     -f drizzle\pg\seed_data.sql
```

#### Linux/macOS:

```bash
# 进入 admin 目录
cd /path/to/memorybook/admin

# 执行表结构恢复
export PGPASSWORD="your-password-here"
psql -h db.xxxxx.supabase.co \
     -U postgres \
     -d postgres \
     -p 5432 \
     -f drizzle/pg/restore_all_tables.sql

# 执行种子数据插入
psql -h db.xxxxx.supabase.co \
     -U postgres \
     -d postgres \
     -p 5432 \
     -f drizzle/pg/seed_data.sql
```

### 步骤 3: 使用快速脚本 (Windows)

我们已经准备了快速脚本：

```powershell
# 编辑 scripts/quick-restore.bat
# 修改连接信息:
set DB_HOST=db.xxxxx.supabase.co
set DB_USER=postgres
set DB_NAME=postgres
set DB_PORT=5432
set PGPASSWORD=your-password-here

# 运行脚本
.\scripts\quick-restore.bat
```

## 🔍 方法三：使用 Node.js 脚本 (需要本地 PostgreSQL)

### 仅在本地有 PostgreSQL 服务时使用

```bash
# 确保 PostgreSQL 服务已启动
# Windows: services.msc 查看 postgresql-x64-xx 服务

cd admin

# 检查数据库连接
pnpm db:check

# 恢复表结构
pnpm db:restore

# 插入种子数据 (需要手动使用 SQL Editor)
```

⚠️ **注意**: 如果遇到 `ECONNREFUSED` 错误，说明本地 PostgreSQL 未运行，请使用方法一或方法二。

## 🐛 常见问题

### 问题 1: 表已存在错误

```
ERROR: relation "memories" already exists
```

**原因**: 表已经存在

**解决**: SQL 脚本使用了 `CREATE TABLE IF NOT EXISTS`，这个错误可以忽略，或者先删除旧表：

```sql
-- 谨慎使用！这会删除所有数据
DROP SCHEMA public CASCADE;
CREATE SCHEMA public;
```

### 问题 2: 外键约束错误

```
ERROR: insert or update on table violates foreign key constraint
```

**原因**: 必须先有 `users` 表数据

**解决**: 先通过 Flutter App 注册一个用户，或手动插入测试用户：

```sql
INSERT INTO users (username, email, password_hash)
VALUES ('test_user', 'test@example.com', '$2a$10$...');
```

### 问题 3: 连接被拒绝

```
ECONNREFUSED ::1:5432
```

**原因**: PostgreSQL 服务未运行

**解决**: 
- 使用 Supabase SQL Editor (推荐)
- 或启动本地 PostgreSQL 服务

### 问题 4: 权限不足

```
ERROR: permission denied for table xxx
```

**原因**: 数据库用户权限不足

**解决**: 使用 Supabase 提供的 `postgres` 超级用户

## 📊 数据库结构总览

### 核心模块

```
用户与认证
  └─ users (用户)

记忆模块
  ├─ memories (记忆)
  ├─ memory_media (媒体)
  ├─ tags (标签)
  ├─ memory_tags (标签关联)
  ├─ memory_comments (评论)
  ├─ memory_likes (点赞)
  └─ memory_favorites (收藏)

相册模块
  ├─ albums (相册)
  └─ album_memories (相册关联)

家庭圈模块
  ├─ family_circles (家庭圈)
  ├─ family_members (成员)
  └─ patients (患者)

健康管理模块
  ├─ health_records (健康记录)
  ├─ health_guides (健康指南)
  └─ memory_reminders (提醒)

病例档案模块
  ├─ medical_categories (分类)
  ├─ medical_records (病例)
  ├─ medical_tags (标签)
  └─ medical_record_tags (标签关联)

位置监控模块
  ├─ location_records (位置记录)
  ├─ geofences (地理围栏)
  └─ geofence_alerts (围栏报警)
```
